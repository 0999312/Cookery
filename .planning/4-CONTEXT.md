## 1. 游戏主界面（烹饪界面）

**决策**: 上方菜单栏 + 左侧材料 + 右侧操作

**布局设计**:

```
┌─────────────────────────────────────────────────────────────┐
│  [烤箱]  [锅]  [发酵器]  [图鉴]  [设置]           [暂停]  │  ← 菜单栏
├──────────────────────────────┬──────────────────────────────┤
│                              │                              │
│   ┌──────────────────────┐   │   ┌──────────────────────┐   │
│   │  基础材料             │   │   │  设备操作区           │   │
│   │  ┌────┐ ┌────┐ ┌────┐│   │   │                      │   │
│   │  │面粉│ │水  │ │盐  ││   │   │  [输入槽1] [输入槽2] │   │
│   │  └────┘ └────┘ └────┘│   │   │                      │   │
│   │  ┌────┐ ┌────┐ ┌────┐│   │   │  [开始烹饪]          │   │
│   │  │糖  │ │黄油│ │鸡蛋││   │   │                      │   │
│   │  └────┘ └────┘ └────┘│   │   │  ┌──────────────────┐│   │
│   │  ...                 │   │   │  │  结果预览         ││   │
│   └──────────────────────┘   │   │  └──────────────────┘│   │
│                              │   └──────────────────────┘   │
│   ┌──────────────────────┐   │                              │
│   │  加工材料             │   │                              │
│   │  (动态材料)           │   │                              │
│   └──────────────────────┘   │                              │
│                              │                              │
├──────────────────────────────┴──────────────────────────────┤
│  状态栏: 已发现 12/50 材料 | 已发现 3/20 配方               │
└─────────────────────────────────────────────────────────────┘
```

**功能说明**:

| 区域 | 功能 | 交互方式 |
|------|------|----------|
| 菜单栏 | 设备选择、图鉴、设置、暂停 | 点击按钮 |
| 材料面板 | 显示可用材料（基础/加工） | 点击选择 |
| 设备操作区 | 输入槽、开始按钮、结果预览 | 拖拽或点击 |
| 状态栏 | 显示发现进度 | 只读 |

**GUIDE 上下文**:
- `game_context` - 主要游戏交互
- 设备选择时切换到 `equipment_context`

## 3. 结果详情弹窗

**决策**: 简单弹窗

**布局设计**:

```
┌─────────────────────────────────────┐
│           烹饪完成!                  │
│                                     │
│           ┌─────────┐              │
│           │  🍞     │              │
│           │  面包   │              │
│           └─────────┘              │
│                                     │
│  标签: cooked, grain                │
│  配方: 面包 (首次发现!)             │
│                                     │
│           [确定]                    │
└─────────────────────────────────────┘
```

**功能说明**:

| 元素 | 描述 |
|------|------|
| 结果图标 | 材料图标（大尺寸） |
| 结果名称 | 材料显示名称 |
| 标签列表 | 输出标签 |
| 配方信息 | 匹配的配方（如果有） |
| 新发现提示 | "首次发现!" 标记 |
| 确定按钮 | 关闭弹窗 |

**GUIDE 上下文**:
- `menu_context` - 确认操作
