# PROJECT.md - Cookery（厨房）

> 最后更新: 2026/05/29

## 项目概述

**名称**: Cookery（厨房）
**类型**: 沙盒烹饪游戏
**引擎**: Godot 4.6.2 stable
**平台**: PC (Windows, macOS, Linux)

## 核心理念

基于"设备即界面"理念的沙盒烹饪游戏。玩家自由搭配材料与制作设备，通过属性标签的变换/组合/消除/增幅，涌现出意料之外的料理成品。

**核心循环**: 材料 → 设备 → 属性变换 → 涌现结果 → 发现

## 当前状态

**已发布版本**: v0.1（原型交付）

**交付内容**:
- 60 种材料、3 种设备、20 个配方
- 完整烹饪系统（变换规则 + 配方匹配 + 动态涌现）
- 6 个 UI 面板（主菜单、游戏、图鉴、暂停、结果、设置）
- 存档系统（3 个槽位 + 自动保存）
- GUIDE 输入系统（3 个上下文）

**代码统计**:
- 25 个 GDScript 文件，~3,023 行
- 6 个场景文件
- 3 个单元测试
