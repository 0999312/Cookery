# REQUIREMENTS.md - Cookery 需求文档

> 最后更新: 2026/05/29

## 需求概述

实现"设备即界面"理念的沙盒烹饪游戏核心玩法，创建可玩的 PC 端游戏原型。

---

## 功能需求

### FR-01: 基础架构（P0 - 必须）

| ID | 需求 | 描述 |
|----|------|------|
| FR-01.1 | 框架 Autoload 注册 | 注册 mc_game_framework 的 7 个 Autoload |
| FR-01.2 | 移除自定义实现 | 删除 scripts/autoloads/ 下的自定义 EventBus/UIManager/AudioManager |
| FR-01.3 | 统一输入系统 | 使用 GUIDE 上下文，移除原生 Input Map |
| FR-01.4 | 清理重复目录 | 删除 common/addons/ 或 addons/ 的重复 |
| FR-01.5 | 修复主菜单 | main_menu.gd 使用框架 API |

### FR-02: 数据系统（P0 - 必须）

| ID | 需求 | 描述 |
|----|------|------|
| FR-02.1 | 材料 Resource | 定义 MaterialData，包含属性标签、名称、描述 |
| FR-02.2 | 设备 Resource | 定义 EquipmentData，包含变换规则、输入槽、输出槽 |
| FR-02.3 | 属性标签系统 | 标签变换（转换、组合、消除、增幅） |
| FR-02.4 | 配方匹配 | 基于属性标签的动态配方匹配 |
| FR-02.5 | 图鉴 Resource | 记录已发现的配方和材料 |

### FR-03: 核心系统（P0 - 必须）

| ID | 需求 | 描述 |
|----|------|------|
| FR-03.1 | 烹饪系统 | 材料放入设备 → 属性变换 → 生成结果 |
| FR-03.2 | 设备交互 | 设备操作界面、材料选择 |
| FR-03.3 | 发现系统 | 新配方被记录到图鉴 |
| FR-03.4 | 分类系统 | 材料和配方的分类管理 |

### FR-04: UI 系统（P0 - 必须）

| ID | 需求 | 描述 |
|----|------|------|
| FR-04.1 | 主菜单 | 开始游戏、设置、退出 |
| FR-04.2 | 游戏界面 | 设备操作、材料选择、结果显示 |
| FR-04.3 | 图鉴界面 | 查看已发现的配方和材料 |
| FR-04.4 | 设置界面 | 音量、显示设置 |
| FR-04.5 | 暂停菜单 | 暂停、继续、退出 |

### FR-05: 输入系统（P0 - 必须）

| ID | 需求 | 描述 |
|----|------|------|
| FR-05.1 | GUIDE 集成 | 所有输入通过 GUIDE 上下文系统 |
| FR-05.2 | 键鼠支持 | 支持键盘和鼠标操作 |
| FR-05.3 | 上下文切换 | 菜单/游戏/设备交互上下文 |

### FR-06: 存档系统（P1 - 应该）

| ID | 需求 | 描述 |
|----|------|------|
| FR-06.1 | 保存游戏 | 保存进度、图鉴、设置 |
| FR-06.2 | 加载游戏 | 加载游戏进度 |
| FR-06.3 | 多槽位 | 支持多个存档槽位 |

### FR-07: 音频系统（P1 - 应该）

| ID | 需求 | 描述 |
|----|------|------|
| FR-07.1 | 背景音乐 | 主菜单、游戏场景背景音乐 |
| FR-07.2 | 音效 | 烹饪、UI 交互音效 |
| FR-07.3 | 音量控制 | 独立的音乐、音效音量控制 |

## 非功能需求

### NFR-01: 性能

| ID | 需求 | 指标 |
|----|------|------|
| NFR-01.1 | 帧率 | 稳定 60 FPS |
| NFR-01.2 | 加载时间 | 场景加载 < 3 秒 |

### NFR-02: 架构一致性

| ID | 需求 | 描述 |
|----|------|------|
| NFR-02.1 | 框架使用 | 必须使用 mc_game_framework 的 API |
| NFR-02.2 | 输入系统 | 必须使用 GUIDE 上下文 |
| NFR-02.3 | 数据驱动 | Resource 子类定义数据 |

### NFR-03: 代码质量

| ID | 需求 | 描述 |
|----|------|------|
| NFR-03.1 | 静态类型 | 所有变量和返回值标注类型 |
| NFR-03.2 | 命名规范 | 遵循 snake_case、PascalCase 规范 |
| NFR-03.3 | 中文文档 | 注释和文档使用中文 |

---

## 约束

| 约束 | 描述 |
|------|------|
| 语言 | GDScript，静态类型 |
| 框架 | mc_game_framework (EventBus/UIManager/Registry/Codec) |
| 输入 | GUIDE 上下文系统 |
| 数据 | Resource 子类，JSON 仅用于外部编辑 |
| 画风 | 扁平化，单色 SVG 图标 |

## 验收标准

### 架构验证

- [ ] project.godot 注册 7 个框架 Autoload
- [ ] 无自定义 EventBus/UIManager/AudioManager 实现
- [ ] 所有输入通过 GUIDE 上下文
- [ ] 无 addons/ 重复目录

### 核心玩法验证

- [ ] 玩家可以将材料放入设备
- [ ] 设备根据属性规则变换材料
- [ ] 变换结果符合预期
- [ ] 新配方被记录到图鉴

### UI 验证

- [ ] 主菜单正常工作
- [ ] 游戏界面可操作
- [ ] 图鉴可查看
- [ ] 设置可调整
